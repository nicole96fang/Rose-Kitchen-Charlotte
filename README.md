# 芳芳的小厨房日记

一个手机优先、无后端、无广告的本地食谱工作台。

## 已完成
- 17 个分类卡片，全部可点击
- 分类页 → 添加新食谱 → 无限食材 / 步骤 / 照片
- 本地 IndexedDB 自动保存，刷新 / 关闭页面后数据仍在
- 食谱大全 / 收藏
- 购买清单：半屏新增、勾选、删除
- 我的：头像、昵称、签名、统计、JSON 备份 / 恢复
- A4 打印样式：沿用应用背景，照片不拆成独立页面
- 分享 PDF：手机浏览器打开系统打印预览后选择“存储为 PDF / 分享”
- 雪花飘落动效
- 使用用户提供的第一张图作为应用背景，并保持原比例，不拉伸

## 图标
当前分类 icon 使用可爱的 emoji 作为占位。后续把你提供的 17 个分类图片放入 `public/assets/icons/` 后，可以在 `src/store.js` 中把 icon 改成图片路径。

## 数据安全
浏览器本地数据不是云端永久存储。建议定期使用「我的 → 导出备份」保存 JSON 文件。Safari 如果清除网站数据，未备份的数据可能无法恢复。

npm run build
